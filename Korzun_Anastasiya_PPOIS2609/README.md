## Что сделано

**BASE**
- `.main-header` — флекс-контейнер: `flex-direction: row`, `justify-content: space-between`.
- `.dashboard-grid` — многострочный флекс-ряд с `flex-wrap: wrap`.
- У карточек `.stat-card` задан `flex-basis: 252px`, фиксированный `width` не используется.
- В конце `css/style.css` есть блок `/* Своими словами */` с ответами на три вопроса.

**JUNIOR**
- Расстояния между элементами шапки и между карточками заданы только через `gap: 22px`, пиксельных `margin` и `padding` для этого нет.
- Кнопка «Выйти из системы» уходит вправо за счёт `margin-left: auto` у самой кнопки, пустых обёрток нет.
- В ветке `homework-10` 4 коммита с тегами `[flex-nav]`, `[flex-grid]`, `[flex-card-inner]`, `[flex-a11y]`.

**PRO**
- `<dl class="meta-list">` — флекс-контейнер с переносом. `dt` занимает 35% строки, `dd` — остаток, поэтому пары стоят в одну строку. На экранах уже 480px у обоих `flex-basis: 100%`, и значение переносится под термин.
- Стресс-тест 320px: у `.card-desc` стоит `overflow-wrap: break-word`, у карточки `min-width: 0`. Длинное слово лога переносится, горизонтальной прокрутки нет.
- `order`: по умолчанию у `.is-lead` `order: 0` (на мобильном первая, как в HTML), от 1024px — `order: 1`, карточка становится последней в ряду.
